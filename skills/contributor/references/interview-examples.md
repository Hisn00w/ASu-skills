# 开源贡献面经案例

本文件只保存公开页面中明确出现的开源经历或开源项目追问，用来帮助 `/contributor` 解释追问路径。它不是企业面试题库，也不代表某家公司固定的面试流程。原帖没有写出的内容必须标为“原帖未记录”，不能根据录用结果或岗位名称补推。

2026-10-12 已核对以下六条公开案例的相关正文。页面有时只返回标题和导航，HTTP 200 不代表正文可读；使用时应核对所选原帖，无法读取或标题不匹配时跳过。下方“待重新核验”条目不能作为公开案例引用。

- 来源：[牛客：B站微服务开发-一面挂经](https://m.nowcoder.com/discuss/570096504870805504)
- 正文核验日期：2026-10-12。

### Galxe 一面

- 正文核验日期：2026-10-12。

## 使用规则

需要引用公开案例辅助面试准备时（本次 PR 的练习题无需先读取公开案例）：

1. 先核对所选案例正文、核验日期和可引用状态，再选与本次事实最接近的案例，并说明相似点和差异；没有直接对应案例时写明没有找到，不强行匹配。只有标题、推荐区或评论不算原帖作者的完整证据。
2. 将公开案例问题标成“原帖明确记录”，将结合用户事实生成的问题标成“基于本次事实生成”。
3. 对每个生成问题绑定 Issue、根因、改动、验证、PR 或组件证据；缺证据就放到“事实缺口”，不要生成第一人称回答。
4. 不把“面试官看了 GitHub”“PR 被提到”解释为合并、采用、加分或录用原因，除非来源原文明确这样说。
