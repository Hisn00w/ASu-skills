# 简历 Bullet Few-shot（领域中立）

本文件用于约束简历 bullet 的形态，不提供可复制的项目素材。生成时只学习“问题/演进 -> 动作 -> 机制 -> 约束 -> 结果”的组织方式；禁止复制本文件中的项目名、数字、技术名词组合或业务场景。

## 使用规则

生成顺序固定为：

1. 从项目事实中抽取 4-6 个候选支柱。
2. 为每个支柱补齐“核心矛盾、我的动作、机制、约束、结果、证据”。
3. 对照下方正例的结构写一级 bullet。
4. 用反例清单逐条重写。
5. 检查每条是否能自然导出一个“为什么这样设计 / 如何权衡 / 如何验证”的面试主问。

few-shot 只用于对齐表达，不允许替代仓库证据。项目没有真实指标时，写可由代码验证的架构结果，并把尚未测量的线上收益标为“待测”或“需验证”；不得为了模仿正例补造数字。

## 正例：分层机制

**项目事实（抽象）**

- 原来的处理逻辑散落在多个入口，新增场景需要重复修改主流程。
- 候选人负责统一异常处理，并参与了主链路改造。
- 代码中存在分类处理、有限重试和降级路径。

**合格 bullet**

> **分层容错：** 针对异常处理逻辑散落、改动容易波及主流程的问题，将错误处理收敛为分层容错机制：按错误类型区分有限重试、降级与快速失败，并统一输出可观测结果，降低新增场景对主链路的改动面；线上收益需通过基线对比验证。

**为什么合格**

- 先说核心矛盾，再说负责的改造。
- 机制不是技术名词罗列，而是说明了如何工作。
- 结果与机制存在因果关系。
- 没有把不可证明的收益写成事实。

## 正例：架构演进

**项目事实（抽象）**

- 旧方案是固定步骤，新增能力需要修改多个节点。
- 候选人主导了从固定流程到可扩展编排的改造。
- 新方案通过统一接口接入不同实现，保留了边界约束。

**合格 bullet**

> **可扩展编排：** 主导将固定步骤的处理流程改造成可扩展的编排结构：抽象统一能力接口，将差异化实现下沉到独立扩展点，并保留输入校验、超时和失败隔离边界，使新增实现主要通过扩展点接入而无需改动核心调度逻辑。

**为什么合格**

- 用“旧方案 -> 新方案”构成清晰演进。
- 说明了抽象、扩展点和核心边界。
- 结果是可验证的架构效果，而非泛泛的“提升效率”。
- 没有把具体文件、函数名写进一级 bullet。

## 反例：功能工单型

```text
- 接入列表分页和筛选功能，优化加载体验（待测）。
- 开发错误弹窗，处理接口异常。
- 增加缓存和重试逻辑，提高接口稳定性。
```

**失败原因**

- 没有说明原问题或演进背景。
- “接入 / 开发 / 增加”没有交代个人动作的边界。
- 没有机制、约束和失败边界。
- “优化体验 / 提高稳定性”不可验证。
- 内容停留在局部功能，无法支撑架构层面的追问。

## 改写对照：从实现动作到工程支柱

**原始描述**

> 接入缓存和重试，优化接口请求。

**合格改写**

> **请求可靠性治理：** 针对下游接口抖动导致的重复请求和延迟放大问题，引入缓存、超时与有限重试机制：仅对幂等请求重试，并设置最大次数和退避边界，避免故障期间形成重试风暴；非幂等请求走快速失败或降级路径，具体延迟收益需通过基线对比验证。

**改写动作**

1. 把“优化请求”还原成可追问的失败模式。
2. 把技术名词改写成机制和适用边界。
3. 补上重试次数、退避、幂等性等约束。
4. 将没有证据的效果改为验证计划，而不是编造指标。

## 生成后硬检查

- [ ] 每条一级 bullet 以 `**通用支柱名：**` 开头；支柱名是面试官可理解的架构/工程能力，不是私有类名或函数名。
- [ ] 每条一级 bullet 只表达一个支柱，不把多个功能并列成清单。
- [ ] 每条至少有“问题或演进 + 机制 + 结果”；关键支柱尽量补充约束或数字。
- [ ] “结果”紧跟机制，能回答“采用它之后系统发生了什么变化”。
- [ ] 没有指标时写架构结果，不能用“提升性能 / 提高稳定性 / 优化体验”代替结果。
- [ ] 真实指标必须来自用户材料、仓库或明确的测量结果。
- [ ] 私有函数、文件路径、内部枚举和业务黑话只进入源码证据索引。
- [ ] `RunManager`、`Stream Bridge`、`execution id` 等项目实现名不能直接充当支柱名；需要时改写为“运行管理”“流式事件桥接”“服务端运行标识”等通用表达。
- [ ] 职责动词与个人参与范围一致，不把局部贡献扩写成 owner。
- [ ] 每条都能导出一个关于设计动机、权衡、边界或验证方式的主问。
- [ ] 没有复制优秀简历样例的项目名、数字、领域名词或指标。
